# GPU session scripts (RTX 4060 laptop, 14 Nov 2026)

The experiments behind `docs/gpu_session/README_HANDOFF.md`: quantization cost (`quantsim.py`), wrong-option
evaluation (`evalw.py`, `evalw2.py`), overgeneration and option benchmarks (`overgen.py`, `optbench.py`,
`optblind.py`), model comparisons (`cmp*.py`), the mix-in experiment (`mix_w.py`). Outputs in `../results/`.
