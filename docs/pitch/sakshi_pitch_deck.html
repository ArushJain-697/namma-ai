Two jobs, one model. The system prompt picks the job: write the question, or write the wrong answers. One combined model beat two specialists at both: held-out loss 1.217 vs 1.227 and 1.429 vs 1.439.

GuardrailsWhat the AI never decides alone

A small model writes imperfect questions. The checks drop the worst.

  1. Code picks the key sentence. The model never chooses what to ask about.

  2. Two separate calls. Question and answer first, wrong answers second.

  3. No giveaways. Wrong options match the answer in length and opening; near-copies and “all of the above” are rejected.

  4. Self-check. A second model answers with shuffled options. If it disagrees, the question is dropped. Of 11 it dropped in one test, about 9 were truly bad.

  5. Proof shown. Every answer comes with the passage sentence that proves it.

The linkWrong answer → belief

Shortlist, rerank, or say nothing

  1. Topic shortlist. 4,000 beliefs down to about 16–50 for this passage.

  2. Retrieve. A small embedding model ranks them (bge-small, 128 MB, ExecuTorch).

  3. Rerank. A cross-encoder reads question and answer together (317 MB, ExecuTorch).

  4. Abstain. Below a confidence line the option stays a plain wrong answer, so we never invent a diagnosis.

The maths1 of 2

Which belief? Has she learned it?

Bayes over the concept's beliefs plus “no specific belief”, so one slip never labels a child. If she holds belief m she picks its option 70% of the time. The next question is the one with the most expected information.

// next question EIG(q) = H(P) − Σₒ P(o)·H(P(·|o)) // found ≥ 75% maybe ≥ 50%

Knowledge tracing separates learning from lucky guesses. Guess rate 0.25 for recall, 0.15 for a real-life question.

// right wrong P(L|✓) = P(L)(1−s)/[P(L)(1−s)+(1−P(L))g] P(L|✗) = P(L)s/[P(L)s+(1−P(L))(1−g)] P(L) ← P(L) + (1−P(L))·0.2

On the way up, each level gets a real-life question. Climb only if right and P(learned) ≥ 0.6. Otherwise re-teach, one more try, then stop and save it as blocked for next time. 0.6 means ready to build on; classic mastery is 0.95.

FSRS-6 predicts forgetting: R(t,S) = (1 + F·t/S)^−w₂₀. Revise first where 1 − mastery × recall is highest: never learned, or probably forgotten.

Later daysMentor Study

She comes back. The belief gets checked again.

  1. Forgetting counts. Mastery today = saved mastery × chance she still remembers.

  2. A new question aimed at each belief she held. Not the same one, which would test memory of the question.

  3. Still there: the fix again, and it comes back sooner. Gone: follow the graph to a related belief with the same root, in another topic.

  4. Finish blocked climbs, then the ideas due today.
